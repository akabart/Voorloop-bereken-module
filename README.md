# Voorloop-rekenmodule Polderbanden.nl

Interne module voor het opzoeken van overbrengingsverhoudingen van trekkers en het berekenen van de
voorloop (voor-/achterasverhouding) bij verschillende bandencombinaties. Vervangt de losse
Excel-bestanden per merk.
